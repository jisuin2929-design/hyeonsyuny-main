# The Daily Prophet & The Marauder's Map

현수 & 수인의 1000일 기념 해리포터 콘셉트 인터랙티브 웹사이트입니다.

- **예언자 일보 (The Daily Prophet)**: `index.html` (메인 신문 페이지)
- **도둑 지도 (The Marauder's Map)**: `map.html` (국내 및 해외 여행지 인터랙티브 지도)

## 기술 구성 및 특징
- GitHub Pages용 순수 정적 웹사이트 (빌드 단계 없음)
- Tailwind CSS (CDN) + Vanilla CSS
- D3.js & TopoJSON 기반 인터랙티브 지도 (2D 평면 지도 & 3D 지구본)
- Web Audio API 기반 오디오 효과음 합성 엔진
- 브라우저 로컬 사진 업로드 (IndexedDB)
